# BANK-MANAGEMENT-SYSTEM

A simple **Bank Management System** developed using **Python**.
This project allows users to perform basic banking operations through a menu-driven console application.

## Features

* Create a new bank account
* Deposit money
* Withdraw money
* Check account balance
* View account details
* Search account
* Exit the system

## Technologies Used

* Python
* Functions
* Conditional Statements
* Loops
* File Handling

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code or any Python IDE.
3. Open the Python file.
4. Run the program.
5. Select the required option from the menu.
